How it works

01 / token image

Live market cap → tier

V4 pool sqrtPrice × Chainlink NVDA/USD gives us real-time USD market cap. Each $10K of marketcap bumps the image up by one tier. 100 tiers, 100 hand-crafted WebP scenes.

02 / NFT phase

Burn $SOCIETY, evolve NFT

1000-supply NFT collection, 1 design × 10 phases (animated GIF). Holders burn $SOCIETY to advance phase: 20K → 30K → ... → 100K per upgrade. Max 540K per NFT for full evolution.

03 / infrastructure

100% on-chain metadata

Token image served via Vercel Edge from /api/metadata. NFT phase read live from contract. No IPFS, no centralized storage. Fully decentralized, fully open.
